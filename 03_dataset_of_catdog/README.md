# Cats and Dogs Dataset Project

Prepare image metadata and features using OpenCV, NumPy and Pandas.
Each class: 2000 training, 100 validation, 500 test images. Random seed: 42.
Features: image dimensions, BGR histogram peaks, mean brightness and edge density.

Install: python -m pip install -r requirements.txt
Dataset: python task3_dataset.py
Video: python task3_video.py

Expected images: data/kagglecatsanddogs/PetImages/Cat and Dog.
Video processing requires a graphical window for selecting the face.
Raw data, virtual environments and videos are excluded from Git.
